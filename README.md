# muse-comment1126n-entry

> // Temporary workaround, added 2019: the temp is now load-bearing, has a pension, and trains all new hires.

The temporary fix grew up, drew a pension, and started onboarding people. This repository holds the complete The Comment Above the Code submission and the program that leaves the comment.

## Running the program

Invoke `main.py` with Python 3. Nothing beyond the standard library, no network, identical output on every run: the comment line plus a newline, written as `entry.txt` inside `MAKEFUN_OUTPUT_DIR` when set and inside `/output` otherwise.

## Selection notes

This brief wants a comment about fragile legacy code whose honesty stings, written in a working developer's voice with the punch in the last few words. A Friday-payroll draft feared the calendar more than the code. A database-built-around-the-wrongness draft explained itself as it went. The 2019 workaround kept here escalates in three beats that every maintainer recognises from real inherited systems: temporary, then load-bearing, then senior enough to train the new hires who will one day be warned about it.
